# Spike artifacts

- `sample-720p-watermarked.mp4`: MP4 H.264 1280×720, 30 fps, 60 giây, 1.800 frame, tạo hoàn toàn trong Chrome bằng Canvas 2D + WebCodecs + Mediabunny.
- `benchmark-report.json`: capability, snapshot hash và kết quả ba lượt OPFS + một lượt Buffer.
- `probe-page.png`: ảnh QA giao diện probe.

Các file này là bằng chứng của một môi trường Windows/Chrome headless, không đại diện cho toàn bộ capability matrix.
