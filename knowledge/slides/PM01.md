## PM01:24

Project Team & Project Manager
Project team
• A set of individuals performing the work of the project to achieve its objectives.
Project Manager
• The person assigned by the performing organization to lead the team that is responsible for achieving the project objective.
• Applies project management knowledge and uses personal and leadership skills to achieve project success.

Supporting structures
• PMO is a coordinating entity for project management:
• In a Functional organization: it helps coordinate across departments.
• In a Matrix organization: it supports resource management and methodologies.
• In a Projectized organization: it ensures standardization and reporting.
• Virtual structure enables cross-boundary collaboration

• A primary function of a PMO is to support project managers in a variety of ways, there are several types of PMOs:

Type of PMO
Degree of Control
Roles and responsibilit y

Controlling
Moderate
Compliance to specific templates, forms, and tools; and conformance to governance frameworks.

Directive
High
Directly managing the projects. Project managers are assigned by and report to the PMO.
